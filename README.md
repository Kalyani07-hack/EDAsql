# Global Tech Layoffs Analysis — SQL Exploratory Data Analysis

A comprehensive SQL-based exploratory data analysis (EDA) on global tech layoffs data — uncovering industry trends, company-wise patterns, 
rolling monthly totals, and year-wise rankings.

 Project Overview

This project performs end-to-end EDA on a cleaned layoffs dataset (`layoffs_staging2`) to answer key business questions: 
Which companies laid off the most?
Which industries were hit hardest?
How did layoffs trend month-over-month? 
Who were the top 5 companies by layoffs each year?

Key Analysis Performed
 1. Basic Exploration
 2. Company-Wise Total Layoffs
 3. Industry-Wise Layoffs
 4. Country-Wise Layoffs
 5. Year-Wise Layoffs
 6. Monthly Rolling Total (Window Function)
 7. Top 5 Companies Per Year (CTE + Dense Rank)

 Skills Demonstrated

- Exploratory Data Analysis (EDA) with SQL
- Aggregate Functions & Grouping
- Date-Based Analysis
- Common Table Expressions (CTEs)
- Window Functions (Rolling SUM, DENSE_RANK)
- Business Insight Generation from Raw Data
